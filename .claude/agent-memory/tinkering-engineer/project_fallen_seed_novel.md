The `/home/david/Dark Romance` project is a creative-writing project: a dark-romance-fantasy novel titled **THE FALLEN SEED**. Two manuscripts now exist in the folder:
- `The_Fallen_Seed.md` — the original adult edition (three acts, 16 chapters + epilogue/author's note, leads aged 26/23, closed-door heat).
- `The_Fallen_Seed_YA.md` — a **YA edition** (~30,500 words, 18 chapters + epilogue, leads aged 18/17, closed-door). Adds YA subplots: Iris (an 11-yr-old being groomed as the next Oracle; Selene's real personal stake — she ends the Oracle-grooming line so Iris goes free), the descent-tether mechanic (Selene can only survive the underworld while holding Kael's hand), Hercules's dead-mortal-mother backstory as the root of his loyalty, and a Kael-was-a-would-be-gardener / Selene-wanted-to-fix-things detail.
- `The_Fallen_Seed_YA.epub` — validated EPUB 3 built from the YA markdown via a Python/zipfile script (mimetype stored-first, minidom-validated XHTML). Build script lives only in the session scratchpad, not the repo.

**Source files and how they relate:**
- `Dark Romans.md` — the authoritative story bible for THE FALLEN SEED (premise, world "Novus Roma", 4 leads, 3-act arc, and a pre-written Chapter One that was preserved verbatim as the novel's opening). This is the canon to keep consistent with.
- `Generic Romance Fantasy.md` — NOT a story; it's a *craft skill* ("epic-romance-fantasy") describing HOW to write the genre. Used as the writing method, not as plot.
- `Terry Brooks.md` — a SEPARATE high-fantasy world ("The Green Between": druids/orcs/Azaroth). Different setting; deliberately NOT merged into THE FALLEN SEED to avoid incoherence.

**Key canon (from Dark Romans.md, do not contradict):** Roman pantheon rules a hidden modern layer via corporations. Jupiter (tyrant-CEO), Juno (real power behind him), Pluto/Hades (exiled, Kael's father), Hercules (demigod enforcer promised godhood via a "pyre" that never comes), Selene (the Oracle, POV), Kael (son of Hades, ate the underworld pomegranate — the "dark fruit" that changes eyes, then appetite, then loyalty). Prophecy: *"The son has risen, fed on the dark fruit... will do to the throne what the throne did to the one before it."*

**Original invented elements I added (keep consistent if continuing):** Verus (Pluto's doorkeeper/psychopomp); Saturn is the true "one before" — freed via the third door ("stop") rather than buried; the wheel breaks through *asking the monster what he wants*; Hercules ascends by choosing what to burn *for*; ending is Kael refusing the throne + a chosen "small life" with Selene, who becomes an Oracle nobody owns.

**Why:** User asked for a complete novel expanding the source material.
**How to apply:** If asked to revise/extend, treat Dark Romans.md as canon and The_Fallen_Seed.md as the current draft; keep heat closed-door unless the user asks to escalate; honor the skill's guardrail against romanticizing coercion (Selene keeps real agency).
